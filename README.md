# Supply Chain & ROI Analysis Dashboard

### Overview
A 3-page Power BI dashboard analyzing 180,519 supply chain 
orders from DataCo Global across 23 regions (2015–2018).

### Key Findings
- OTD Rate: 45.17% vs 95% industry benchmark
- 98,977 late orders identified
- $2.17M cost of late deliveries
- 82.43% projected ROI from supply chain improvement
- Central America: highest late delivery volume (15,518 orders)
- Second Class shipping: worst delay performance (1.9 avg delay days)

### Tools Used
- Power BI Desktop (DAX, What-If Parameters)
- SQL (DB Browser for SQLite)
- DataCo Global Dataset (Kaggle — 180,519 records)

### Dashboard Pages
1. Executive Overview — KPI cards, OTD by region, order status
2. Operations Drill-Down — Shipping mode, category, delivery matrix
3. Financial Appraisal — ROI card, What-If simulation, profit analysis

DataCo Smart Supply Chain Dataset
